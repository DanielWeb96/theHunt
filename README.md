## 🗺️ Big Urban Battlefield Map

* **2048 x 2048 Big Urban Map**: Cracked asphalt roads, abandoned police cars, military sandbags, shattered storefronts, and crosswalks.
* **Smooth Camera Tracking**: Follows your player with smooth viewport scrolling and a real-time radar / minimap.
* **Co-op Multiplayer (WebRTC P2P)**:
  * Play with friends via room codes.
  * Real-time position, aiming, weapon fire, and ability synchronization.
  * In-game team radio comms.
* **Procedural 16-bit Web Audio**: Class-specific gunshots, reloads, explosions, and zombie groans.

## 🎮 Controls

* **`[W, A, S, D]`** or **`[Arrow Keys]`** — Move Survivor
* **`[Mouse Aim + Left Click]`** — Shoot Weapon
* **`[R]`** — Reload Magazine
* **`[Space]`** or **`[Right Click]`** — Use Class Ability
* **`[Enter]`** — Send Team Radio Chat
